# 05. Внутрипамятная Генерация PBR-Текстур Брони (HTML5 / Three.js / Canvas)

Если ассет генерируется для WebGL или без внешних PNG-файлов:
- Текстуры Albedo, Bump и Roughness генерируются процедурно через 2D-холст (`Canvas`) за 2 миллисекунды.
- Вдоль линий фасок (`U = 0.0, 0.25, 0.50, 0.75`) рисуются темные швы стыков и ряды шестигранных болтов.
- На плоских участках штампуются военные трафареты (`ARMOR 46100`, `DANGER // EXHAUST`).
- Полный код генератора содержится в файле `09_PRODUCTION_SCRIPTS_AND_TEMPLATES/dreadnought_agent_skill_guide.md`.
