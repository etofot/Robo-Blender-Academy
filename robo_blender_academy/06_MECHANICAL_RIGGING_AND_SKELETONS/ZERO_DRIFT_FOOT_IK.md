# 06. Аналитический Zero-Drift Foot IK для Шагоходов

В шагоходах и роботах-дредноутах проскальзывание ног по земле полностью уничтожает ощущение колоссального веса боевой машины.

### Принцип Фиксации Стопы (Zero-Drift Foot Lock)
Вместо приближенных итеративных численных солверов (CCD), используй точное аналитическое решение треугольника бедра и голени через теорему косинусов:

```
        Hip [p0]
         o
        / \
    L1 /   \
      /     \  Расстояние D = ||p_target - p0||
     o       o Target Foot [p_target]
    Knee [p1]
```

$$\cos(\alpha) = \frac{L_1^2 + D^2 - L_2^2}{2 L_1 D}$$

1. Нога привязана к цели стопы на земле.
2. Стопа поворачивается строго параллельно плоскости террейна.
3. Корпус робота покачивается и приседает, пока стопа остается абсолютно неподвижной в точке опоры.
