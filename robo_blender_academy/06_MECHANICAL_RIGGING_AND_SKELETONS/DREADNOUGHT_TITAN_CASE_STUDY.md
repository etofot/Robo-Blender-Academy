# 06. Кейс-Стади: Шагоход Dreadnought MK-IV TITAN

Полный эталонный пример боевого тяжелого шагохода из реального боевого проекта.

---

## 1. Спецификация Узлов и Костей

| Узел | Родитель | Позиция `[X, Y, Z]` | Описание |
| :--- | :--- | :--- | :--- |
| `root` | - | `[0.0, 0.0, 0.0]` | Базовый якорь на грунте |
| `pelvis` | `root` | `[0.0, 0.0, 0.0]` | Тазовый узел, центр тяжести для приседаний и наклонов |
| `torso` | `pelvis` | `[0.0, 0.10, 0.0]` | Поворотный бронекорпус с ядерным реактором |
| `sensorPod` | `torso` | `[0.0, 1.08, 0.42]` | Бронированная голова с рубиновой оптикой |
| `hatchL / R` | `torso` | `[±0.42, 1.44, -0.05]` | Створки ракетных шахт |
| `shoulderL / R` | `torso` | `[±0.98, 0.92, 0.0]` | Наплечные бронещиты (Pauldrons) |
| `armL` | `torso` | `[-0.98, 0.92, 0.0]` | Левая рука: рельсотрон (Railgun) с гидрооткатом |
| `armR` | `torso` | `[+0.98, 0.92, 0.0]` | Правая рука: силовой кулак с роторным захватом (Power Claw) |
| `legL / R` | `pelvis` | `[±0.54, -0.12, 0.0]` | Тазобедренные шарниры |
| `kneeL / R` | `legL / R` | `[±0.62, -0.86, 0.12]` | Коленные суставы обратного сгиба ($L_1 = 0.754$ м) |
| `ankleL / R` | `kneeL / R` | `[±0.66, -1.72, 0.02]` | Голеностоп и массивные подошвы ($L_2 = 0.866$ м) |
