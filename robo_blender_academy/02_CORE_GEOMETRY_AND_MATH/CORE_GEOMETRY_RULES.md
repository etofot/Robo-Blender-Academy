# 02. Математические Правила Построения Геометрии (Core Geometry Rules)

Этот свод правил предотвращает три главные ошибки ИИ-агентов, из-за которых 3D-модели разваливаются в пространстве («эффект взорванной модели»).

---

## Правило 1: Всегда используй `size=2` для кубических примитивов

Куб, созданный с `size=S`, имеет вершины на расстояниях $\pm S/2$ от центра.
- При `size=1` вершины находятся на $\pm 0.5$. Если задать `scale=(0.4, 0.4, 0.4)`, итоговый полуразмер будет $0.2$, а не $0.4$! Это незаметно уменьшает модель ровно в 2 раза.
- При `size=2` вершины находятся строго на $\pm 1.0$. После `scale=(sx, sy, sz)` полуразмеры детали равны в точности `(sx, sy, sz)`, а габариты — `(2*sx, 2*sy, 2*sz)`.

```python
# ПРАВИЛЬНО: size=2
bpy.ops.mesh.primitive_cube_add(size=2, location=(0, 0, 1.0))
box = bpy.context.active_object
box.scale = (0.50, 0.25, 0.10)  # Габариты: 1.0м по X, 0.5м по Y, 0.2м по Z
```

## Правило 2: Соединение точек через BMesh Beams (Без вращений Эйлера)

Никогда не пытайся соединить две точки в пространстве цилиндром, вращая его через `rotation_euler`. Порядок вращения Эйлера (XYZ) почти гарантированно повернет деталь не по той оси.  
Используй функцию `make_beam` из модуля `geometry_utils.py`:

```python
from geometry_utils import make_beam

# Создает балку прямоугольного сечения, идущую строго из точки start в точку end
piston_arm = make_beam("HydraulicPiston", start=(0.2, 0.5, 0.1), end=(0.4, 0.8, 0.6), hw=0.03, hh=0.03)
```

## Правило 3: Мгновенное применение Transform внутри циклов

Если скрипт создает массив деталей (траки гусениц, бронеплиты, болты) и меняет их масштаб:
```python
# ПРАВИЛЬНО: transform_apply сразу внутри цикла для каждого объекта
for i in range(10):
    bpy.ops.mesh.primitive_cube_add(size=2, location=(0, i * 0.2, 0))
    plate = bpy.context.active_object
    plate.scale = (0.1, 0.08, 0.02)
    bpy.ops.object.transform_apply(location=False, rotation=False, scale=True)
```

## Правило 4: Замер соседей через `verify_bounds` вместо угадывания чисел

Никогда не прописывай длину соединительных балок и панелей «на глаз». Считай границы соседних деталей:
```python
from geometry_utils import verify_bounds

b_hull = verify_bounds("TankHull")
b_turret = verify_bounds("TurretBase")

# Точная высота проставки между корпусом и башней
spacer_z = (b_turret['z'][0] + b_hull['z'][1]) / 2.0
```

## Правило 5: Компенсация усадки SubSurf (+13%) или выбор Bevel

Subdivision Surface стягивает сетку внутрь на 10-15%.
Для военной техники и роботов **всегда предпочитай модификатор `BEVEL`** с сегментами 1-2 и `limit_method='ANGLE'`. Он делает кромки реалистично сбитыми, но оставляет грани абсолютно прямыми.
