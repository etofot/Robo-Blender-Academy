### КЛАСТЕР 1: AI Concept to 3D и Рельефы из Глубины (Image to 3D & Depth)

#### `Image to 3D` (v1.1.8 / v1.1.0)
- **Путь:** `ADDONS new/Imageto3Dv1.1.8.zip` (новая версия) / `ADDONS2/Image_to_3D_v1.1.0.zip`
- **Суть:** Локальная генерация 3D-модели по одному 2D-изображению на базе **TRELLIS.2** (Microsoft) и **Hunyuan3D-2.1** (Tencent).
- **Что нового в v1.1.8:** Встроенное оптимизированное ядро `trellis2` со sparse attention, улучшенный модуль удаления фона `rembg` и кастомный растеризатор для GPU без внешних зависимостей.
- **Инструкция для Агента:**
  1. Создает первичный объемный блок-аут робота/техники по 2D-арту за 1–3 минуты прямо на локальной видеокарте.
  2. Выходной файл `.glb` импортируется в сцену через `bpy.ops.import_scene.gltf(filepath=...)`.
  3. Агент снимает габариты через `verify_bounds()` и использует сгенерированный меш как 3D-шаблон под твердотельную сборку брони.

#### `zForm` (v2.4.3)
- **Путь:** `ADDONS new/zform_2.4.3.zip`
- **Автор:** Viz Life Studio (Blender 3.6.0+)
- **Суть:** Мгновенное превращение плоских изображений и карт глубины (Depth Maps) в высокополигональные 3D-меши, барельефы и метод **ShadowBox**.
- **Инструкция для Агента:**
  1. **ShadowBox Моделирование:** Позволяет формировать базовые силуэты бронеплит, крыльев и оружия из силуэтных черно-белых масок (аналог ShadowBox в ZBrush).
  2. **Рельефная Броня и Эмблемы:** Выдавливание барельефов фракций, гербов, тактических знаков и сложного мелкого рельефа брони из карт нормалей/высот без скульптинга вручную.
  3. **360° Иммерсивные фоны:** Проекция панорамных изображений с картами глубин для создания интерактивного заднего плана в сцене.

### КЛАСТЕР 2: Тяжелый Булевый Хард-Серфейс

#### `Hard Ops 26.1` & `Boxcutter 26.1`
- **Суть:** Абсолютные лидеры хард-серфейс моделирования.
- **Инструкция для Агента:**
  1. **Запрет на интерактивные модальные окна в фоне:** Boxcutter ориентирован на мышь. При работе через Python-скрипты агент не вызывает интерактивный Boxcutter, а использует API Hard Ops или прямой BMesh-булевый пайплайн.
  2. **Оператор sSharpen / CSharpen в Hard Ops:**
     `bpy.ops.hops.csharpen()` автоматически помечает острые ребра (`mark_seam`, `mark_sharp`), выставляет угол автосглаживания нормалей (Auto Smooth 30° / 60°) и накладывает взвешенные нормали (`Weighted Normal` модификатор).
  3. **Служебная коллекция каттеров:** При вырезании пазов все каттеры помещаются в `CUTTERS_TEMP` со статусом `hide_render = True`.

#### `Fluent 4.3 Power Trip`
- **Суть:** Полностью неразрушающий булев моделинг с сохранением живой параметрической фаски и возможностью нарезать провода и вентиляционные решетки прямо по телу детали.
- **Инструкция для Агента:** Идеален для создания многослойной брони: позволяет делать внутренний сдвиг (Inset) бронеплиты и автоматически скруглять внутренние пазы.

#### `Bool Tool 2.0`
- **Суть:** Быстрый неразрушающий булевый инструмент на горячих клавишах `Ctrl+Shift+NumPad_Minus` (Difference), `Plus` (Union), `Slash` (Slice).
- **Инструкция для Агента:** Для нарезки брони на куски метод **Slice** (`btool.boolean_slice`) за один вызов разделяет монолитный корпус на две независимые бронеплиты с технологическим зазором.

### КЛАСТЕР 3: Прецизионная Топология, Фаски и Врезка Деталей

#### `MESHmachine` (v0.21 / v0.6.9)
- **Суть:** Спасение для топологии без Subsurf.
- **Инструкция для Агента:**
  1. **`Unbevel / Unchamfer` (Откат фасок):** Вызов `bpy.ops.machin3.unchamfer()` превращает запеченную фаску обратно в чистое ребро 90°. Агент может исправлять геометрию на любом этапе.
  2. **`Boolean Cleanup`:** После булева вычитания запускается `bpy.ops.machin3.boolean_cleanup()`. Аддон стягивает микро-ребра и убирает артефакты вершин.
  3. **`Normal Stashes`:** Копирует неискаженные нормали до булевых операций и восстанавливает их на стыках, полностью ликвидируя затенения.
  4. **`Plugs` (Врезка узлов):** Позволяет программно вставлять в искривленную броню готовые узлы (гнезда питания, порты сенсоров, петли люков).

#### `MACHIN3tools` (DeusEx v1.13.3 / v0.3.15)
- **Суть:** Ускорение работы со сложной сеткой.
- **Инструкция для Агента:**
  - `Smart Vert`: Автоматическое сведение ребер брони до пересечения (Slide Extend).
  - `Clean Up`: Автоматическая санитария импортированных или сгенерированных мешей (`bpy.ops.machin3.clean_up()`).
  - `Align`: Выравнивание деталей робота по трем осям без ручного высчитывания матриц.

- **Путь:** `ADDONS new/smoothWeights v3.0.zip`
- **Автор:** Ingo Clemens (Brave Rabbit — создатели топового риггинг-софта для Maya и Blender).
- **Суть:** Продвинутое топологическое сглаживание весов скиннинга (Laplacian Smoothing) взамен стандартной проблемной кисти Blender Smooth.
- **Почему это критично для робототехники и персонажей:**
  1. **Защита Нормализации 1.0:** Стандартная кисть сглаживания в Blender часто нарушает сумму весов $1.0$ или "размазывает" вес на далекие случайные кости. `smoothWeights` гарантирует строгое сохранение суммы весов $1.0$.
  2. **Устранение Заломов на Суставах:** Идеально сглаживает переходные зоны между жесткой броней и гибкими гофрами, кабелями, шарнирами локтей, коленей и пальцев.
  3. **Поддержка Топологической Симметрии (Symmetry Map):** Позволяет симметрично переносить и сглаживать веса даже на слегка асимметричных сетках.
  4. **Инструкция для Агента:**
     - Вызывается в режиме Weight Paint на выделенные вершины:
     - Обеспечивает плавную деформацию без потери объема сустава (Volume Loss Prevention).

## 📋 Памятка Командного Вызова Аддонов из Python для Агента

```python
import bpy

# 1. Установка и включение любого аддона из ZIP
def install_and_enable_addon(zip_path, addon_module_name):
    bpy.ops.preferences.addon_install(filepath=zip_path)
    bpy.ops.preferences.addon_enable(module=addon_module_name)
    print(f"Addon {addon_module_name} successfully enabled!")

# 2. Безопасное применение Hard Ops CSharpen
def apply_hops_csharpen(obj):
    bpy.context.view_layer.objects.active = obj
    obj.select_set(True)
    if hasattr(bpy.ops, 'hops') and hasattr(bpy.ops.hops, 'csharpen'):
        bpy.ops.hops.csharpen()
    else:
        # Fallback: стандартный авто-смуз и взвешенные нормали
        obj.data.use_auto_smooth = True
        mod = obj.modifiers.new(name="WeightedNormal", type='WEIGHTED_NORMAL')
        mod.keep_sharp = True

# 3. Управление Geometry Nodes аддонами (Higgsas / BY-GEN)
def set_geonode_parameter(obj, modifier_name, param_name, value):
    mod = obj.modifiers.get(modifier_name)
    if mod and mod.type == 'NODES':
        mod[param_name] = value
        print(f"Updated {param_name} to {value}")
```
