# 03. Конформная Топологическая UV-Развертка Бронеплит

> [!CAUTION]
> **Проблема «Спортивного костюма»:** Если накладывать текстуру на робота через обычный Triplanar или Box Mapping, линии швов и болтов режут наклонные бронеплиты под нелепыми углами, растягиваясь на фасках.

---

## Принцип Конформной Параметризации (Conformal Topology UVs)

В боевом генераторе робота (например, `dreadnought_agent_skill_guide.md`) геометрия бронеплит строится лофтингом поперечных 8-гранных колец сечений (`slices`).  
Развертка создается прямо во время генерации вершин:

1. **Координата `U` (`0.0 .. 1.0`)** — бежит строго по периметру контура бронеплиты (`i / nPts`).
2. **Координата `V` (`0.0 .. 1.0`)** — идет снизу вверх вдоль колец (`r / (numRings - 1)`).
3. Для 8-гранного блока со скошенными углами (`nPts = 8`):
   - Углы ребер бронеплиты ВСЕГДА попадают в точные UV-координаты: `U = 0.0, 0.25, 0.50, 0.75`.
   - Нижняя фаска лежит строго в диапазоне `V = 0.00 .. 0.10`.
   - Верхняя фаска лежит строго в диапазоне `V = 0.90 .. 1.00`.

```python
# Построение развертки в процессе натяжения полигонов по сечениям
for r in range(num_rings - 1):
    v0 = r / (num_rings - 1)
    v1 = (r + 1) / (num_rings - 1)
    for i in range(n_pts):
        u0 = i / n_pts
        u1 = (i + 1) / n_pts
        
        # Топологический квад из двух треугольников с точными UV
        uv_quad = [
            (u0, v0), (u1, v0), (u1, v1),
            (u0, v0), (u1, v1), (u0, v1)
        ]
```

### Результат:
- Сварные швы и болты на текстуре ложатся строго вдоль фасок брони.
- Ребра жесткости и вентиляционные жалюзи оказываются строго по центру плоских граней.
- 0 растяжений, 0 искажений.
