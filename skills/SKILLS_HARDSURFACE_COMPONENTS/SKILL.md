# Hard-Surface Mech Components Skill & Academy Masterclass

Эта библиотека содержит математические алгоритмы и процедурные Python-скрипты на базе `bmesh` для процедурного создания высококачественных промышленных узлов роботов мастер-класса (100% CAD Hard-Surface).

## Принцип 4-слойной архитектуры (Four-Layer Architecture Rule)
1. **Слой 1: Силовой каркас (Chassis & Pivots)** — несущие швеллеры, зубчатые венцы (Sunburst Hubs), стальные шпиндели, карданные кольца.
2. **Слой 2: Кинематика и приводы (Actuation)** — сдвоенные параллельные гидроцилиндры, полированные штоки, шаровые наконечники, гибкие бронешланги.
3. **Слой 3: Вспомогательные системы (Thermal & Subsystems)** — оребренные бачки-аккумуляторы, щелевые радиаторы (louvers), пружинные узлы отбоя (travel-stops), клеммные коробки.
4. **Слой 4: Составная фацетированная броня (Segmented Armor)** — раздельные щиты с фасками, технологическими зазорами (Reveal Gaps 8–15 мм) и смотровыми окнами для обзора механизмов.

## Доступные генераторы в каталоге `scripts/`:

### 1. `build_sunburst_gear.py` (Радиальные зубчатые венцы)
- **Назначение**: Создание поворотных венцов суставов (колено, лодыжка, плечо) с клиновидными зубьями, осевыми стаканами и посадочными местами подшипников.

### 2. `build_bolt_pattern.py` (Разметка болтовых кругов PCD)
- **Назначение**: Процедурное размещение конструкционного крепежа (болты, гайки, заклепки, потайные выборки) по окружности заданного диаметра.

### 3. `build_cable_chute.py` (Сегментированный бронированный кабель-трап)
- **Назначение**: Моделирование гибких защитных рукавов питания и кабель-трасс над подвижными шарнирами.

### 4. `build_finned_canister_block.py` (Оребренный теплообменный блок)
- **Назначение**: Создание сдвоенных баллонов высокого давления с кольцевыми ребрами охлаждения на H-образном кронштейне.

### 5. `build_articulated_foot.py` (Адаптивная карданная стопа)
- **Назначение**: Построение 4-палого аутригера с центральным карданным блоком (Gimbal), арочным клиренсом ($85\text{ мм}$), микрогидравликой подвески и резиновыми башмаками.
